# 2026-09-08

## Changed

- Game Control 六项基础属性上限统一遵循服务端职业配置，支持配置为 32767，保留原有状态计算公式。
- 地图传送改用 HappyRO 专用请求与结构化响应，统一返回权限、跨地图、冷却、地图规则、坐标和执行结果；客户端只有在服务器确认成功后才开始冷却。
- Game Control 增加在线角色实时快照，并在等级、职业和属性修改后立即保存角色状态。
- 增加游戏内角色维护和游戏设置开放范围，均支持“所有人 / 管理员”并默认对所有玩家开放。
- Game Control 将可读设置及其最小/最大值集中到单一编译期定义，读取和应用使用同一套服务端校验边界。
- 将 battle-config 命令处理从 Socket 消费入口抽出，保持主线程状态访问不变并降低入口复杂度。
- 角色属性维护允许使用完整服务端整数范围，不再被普通角色属性上限 99 限制。
- 角色职业维护允许使用职业 ID 0，以支持切换为初心者。
- 角色快照和职业维护结果统一返回职业数据库 ID，避免职业切换后客户端回退为初心者。

## Fixed

- 修复高属性角色使用带命中加成的技能时，16 位命中率中间值溢出并造成零伤害的问题。
- 修复拆分后的 battle-config 读取响应被序列化为数组而非对象的问题。
