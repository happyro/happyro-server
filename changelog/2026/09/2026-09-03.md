# 2026-09-03

## Added

- 增加默认关闭、仅允许回环地址访问并使用 Bearer 认证的 Game Control HTTP 端点。
- 增加 web-server 到 map-server 的 Unix Socket 转发和 map-server 主线程命令队列。
- 增加角色等级、职业、属性重置、技能重置和状态恢复命令。
- 增加在线角色附近魔物召唤、合法格搜索和自动清理。
- 增加白名单经验与掉落倍率应用、实际值回读和能力发现。
- 增加 login、char、map、web 四个物理部署 systemd 服务模板。

## Documentation

- 记录物理部署模板、Socket 运行目录、服务依赖、启用前置和回滚检查。
- 明确 HTTP 端点仅负责认证和转发，运行时操作由 map-server 主线程执行。
- 明确 Game Control 只允许 loopback HTTP，不可直接暴露到外部网络。

## Fixed

- 防止 web-server 调试请求日志输出 `Authorization` 凭据。
- 在启用 Game Control 但缺少 Socket、回环绑定或足够长度密钥时拒绝启动。
- 允许后台服务组访问 Unix Socket，并支持字符串形式的角色 ID。
- 对命令 payload 执行完整类型、字段和范围校验，避免异常输入中断 map-server。
- 在执行角色多字段更新前完成全部校验，避免失败请求留下部分修改。
- 在倍率批量应用失败时恢复已修改值，并拒绝重复键和未注册键。
- 防止第二个 map-server 实例删除正在使用的 Game Control Socket；仅在确认现有 Socket 已失效后清理并接管路径。
