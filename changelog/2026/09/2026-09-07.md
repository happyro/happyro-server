# 2026-09-07

## Added

- 新增网页地图传送的开放范围、跨地图开关和冷却时间战斗配置，默认向所有玩家开放，并支持通过 Game Control 即时应用。
- 地图服务器向在线客户端下发传送能力，配置变更后立即刷新所有在线角色。
- 新增游戏内魔物图鉴召唤策略、冷却、自动清理和 Boss/MVP 开关，并向在线客户端即时下发召唤能力。
- 客户端可通过专用封包请求在当前角色附近召唤单只临时魔物；Game Control 与游戏客户端共用同一套合法格搜索、生成和清理实现。

## Security

- 网页地图传送在服务器端强制校验开放范围、地图限制和冷却，不向普通玩家开放 `@mapmove` 命令权限。
- 游戏内召唤由服务器强制校验账号权限、魔物 ID、Boss/MVP 策略、GvG 地图和冷却，客户端不能指定数量、范围或存活时间。
