# 2026-09-09

## Added

- Game Control 增加在线角色背包物品发放命令，支持物品有效性、数量、负重、格数和堆叠限制校验，并在成功后即时保存角色。
- 已完成的背包发放命令会在 map-server 中短期缓存结果，重试同一命令不会重复增加物品。
- 游戏规则增加冒险工具物品发放开放范围，默认允许所有玩家。
- Game Control 增加在线角色技能点直接设置命令，支持即时通知、保存和最高 32767 点测试额度。
- Game Control 增加在线角色 Zeny 发放命令，与物品发放共用幂等结果缓存并拒绝超过角色持有上限的请求。

## Fixed

- Game Control 应用经验或掉落倍率后会立即重载魔物数据库，使新倍率实时作用于经验和物品掉落计算。
- Game Control 补齐普通魔物与 MVP 的恢复品、消耗品和装备掉落倍率设置。
- 冒险工具召唤魔物的默认存在时间由 60 秒调整为 600 秒。
- 角色维护修改职业或职业等级后会按当前职业的完整前置阶段补足应得技能点，同时保留已额外配置的测试点数。
- 战斗状态属性使用与原字段同宽度的无符号数值，避免基础属性 32767 叠加职业或装备加成后发生符号溢出并导致伤害异常。
