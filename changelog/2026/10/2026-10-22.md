# 2026-10-22

## Added

- `[server]` 游戏控制接口新增 `account.disconnect`，按账号定位当前地图会话，通过正常断线与存档流程踢下线，并关闭离线商店；账号不在地图服时返回未断开状态。

- `[server]` 新增 char-server 账号删除队列执行器与心跳；阻止删除中账号重新认证，等待地图服退出与最终存档确认后逐角色清理，保留任务进度与失败重试状态。
- `[server]` 地图服存档确认携带任务随机编号，断线重连后重新确认；离线商店记录按明细、主表顺序清理。

## Fixed

- `[server]` 地图服收到管理后台账号删除通知时立即标记会话，拒绝等待断线期间的角色控制命令，防止排队中的发放、金币及属性操作继续修改待删除角色；保留最终存档确认后才允许清理的约束。

- `[server]` 角色清理遇到数据库错误时停止并保留角色主记录；公会、队伍和关联对象清理错误向上返回，避免记录错误后仍报告删除完成。

- `[server]` Web 与地图服共用游戏控制命令格式校验，在读取字段和命中执行缓存前拒绝错误类型、空标识及超长标识，避免本地控制请求触发 JSON 类型异常。

- `[server]` 设置应用命令强制携带地图服实例和预期版本，拒绝进程重启前或版本过期的请求，保留最近执行凭据供恢复查询。

- `[server]` 新增设置版本屏障命令，与设置应用在地图线程上竞争同一预期版本；屏障只推进版本，不修改设置，使尚未执行的旧请求失效。

- `[server]` 删除角色时先清理其收件附件中宠物蛋引用的宠物记录，再删除邮件；保留已寄给其他角色的邮件及宠物蛋，避免孤立宠物记录。

- `[server]` 管理员删除账号在角色清理前检查其卖方或买方拍卖；未结算时保留全部角色数据并返回 `active_auction`，由正常拍卖流程结算后再重试，避免破坏其他玩家的托管物品与出价。

- `[server]` 删除父母角色时清理子女对其引用并同步 char/map 缓存，保留存活父母和子女技能；存档前核对父母存在性，防止延迟存档恢复已删除关联，查询失败时拒绝该次保存。

- `[server]` 角色存档返回实际 SQL 错误；失败时不发送最终存档确认、不标记离线，让地图服保留退出存档并重试，避免账号删除屏障在存档失败后提前放行。新增真实报文处理函数的失败、重试成功、普通存档和不完整报文回归测试。

- 游戏库账号唯一约束与邮件回执 SQL 统一由 happyro-server 提供；API 仅检查结构，移除游戏库 DDL 命令，数据库容器初始化直接使用服务端 SQL。
