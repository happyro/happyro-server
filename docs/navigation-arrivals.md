# 冒险工具默认传送落点

## 选择规则

`HAPPYRO_MAP_TELEPORT` 和游戏控制接口的坐标 `(0,0)` 表示请求自动选择落点，不再表示随机落点。封包结构和 PACKETVER=20211103 不变。非零坐标仍作为明确目标处理。

1. 已配置的十四城使用固定默认坐标，并在附近十二格内进行安全校验与调整。
2. 其余名单地图按顺序查找当前已加载的服务 NPC，检查地图、可见性及角色可用性，在其当前位置周围二至六格内寻找安全格。一个候选不可用时继续下一个。
3. 已审核的普通地图入口使用 `happyro_entrance_arrivals` 中的入口安全锚点；附近十二格调整需与锚点步行连通，锚点不可通行或无同区域安全格则拒绝。
4. 其余没有合适服务 NPC 或入口规则的地图，从地图中心向外逐圈寻找安全格，最多搜索覆盖整张地图的范围；仍无可用位置则拒绝传送，不随机回退。

所有分支保留传送权限、跨地图开关、冷却、禁止传入/传出地图和职业进入限制。自动落点不授予额外权限，不修改任务脚本。显式坐标仅在附近十二格内调整，不转去服务 NPC。脚本原有传送阵与普通跨图寻路不变。

安全格要求可通行、未被角色或 NPC 占用，且避开完整 OnTouch 区域和其两格边距。实际可用性以运行中的服务端为准。
